# Happy Birthday, Vismaya 🎂✨

A warm, interactive birthday website made for Vismaya, a friend.

## Current version
- One portrait birthday photo: `assets/vismaya-birthday-memory.jpg`
- Scratch-to-reveal gift-card animation
- Birthday-themed photo frame, ribbon and sparkles
- Balloons, confetti, music and interactive sections
- Friendly, cheerful wording — not romantic

## Run locally
Open `index.html` in a browser, or use VS Code + Live Server.

## Customize
- Replace `assets/vismaya-birthday-memory.jpg` to use another photo.
- Replace `assets/birthday-music.mp3` to use another song.
- Main text and messages are inside `index.html`.
- Visual styling and the gift-card animation are in `style.css`.
